# Villa Rentals Goa

A design-reference demo website for a private-pool villa rental business in Goa.
Built with Vite, React and TypeScript.

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:5173/.

## Production build

```bash
npm run build
npm run preview
```

## Note

This is a demonstration build. Property details, nightly rates, contact numbers and
availability shown on the site are illustrative sample content, not live data.
